How to read the Blender GPU comparison

The dataset is a useful public reference when the exact Blender release and rendering backend are kept in view. It is not a substitute for testing a complete system under your own workload.

What these numbers mean

Blender Open Data describes the benchmark score as an estimate of Cycles samples rendered per minute, summed across the benchmark scenes. The hub snapshot uses Blender 4.4.0 with OptiX and the published device medians. The sample count is shown beside each median.

Keeping the software version and backend constant avoids mixing scores from different named configurations. It does not make the records a controlled lab test: submissions come from community machines with different processors, memory, drivers, cooling, and other system conditions. Treat small differences cautiously and use the linked query for context.

Why the RTX 4070 is not in this chart

The curated rows are from the exact Blender 4.4.0 + OptiX query snapshot. The base RTX 4070 did not appear in the verifiable query excerpt captured for this release, so it is omitted rather than filled with an all-version or mixed-backend value. The separate Kyle Tech Testing RTX 4070 report is a short ComfyUI telemetry evaluation and is not a Blender score.

Useful interpretation

  • The median reduces the influence of unusually high or low submissions, but is not a guarantee for a specific system.
  • Benchmark counts indicate the quantity of submitted records, not independent labs or unique owners.
  • These figures describe Blender Cycles rendering; they do not predict gaming frame rates, AI generation time, video encoding, power efficiency, or temperature.
  • Do not compare a laptop GPU to a desktop GPU from a different query without discussing the power and system context.
